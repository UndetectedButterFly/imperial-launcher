# Империя — лаунчер сборки

Небольшая программа для Windows, которая ставит и обновляет сборку сервера «Империя» (Minecraft 1.21.1, NeoForge, Create, MineColonies). Вам не нужно вручную скачивать моды и конфиги: лаунчер делает это сам и при каждом обновлении докачивает только то, что изменилось. Ваши личные файлы (раскладка клавиш, настройки модов, миры, скриншоты) он не трогает.

Работает с Freesm Launcher, Prism Launcher, Modrinth App и любым другим лаунчером, если указать папку игры.

## Установка

1. Откройте вкладку **Releases** этого репозитория и скачайте `ImperialLauncher.exe`. Положите его в любую обычную папку (не в Program Files).
2. Запустите. Если Windows пишет «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае» (у программы нет платной подписи).
3. Дальше выберите свой случай.

### Новая установка (у меня ничего нет)

1. Нажмите **«Установить сборку»**. Лаунчер скачает Freesm и сборку в папку `C:\Users\<имя>\ImperialMC`. Другую папку можно выбрать заранее: «Настройки» → «Папка установки».
2. Дождитесь «Готово».
3. Один раз добавьте аккаунт: вкладка **«Игрок»** → впишите ник → «Сохранить» → «Открыть Freesm» → Аккаунты → Добавить оффлайн с тем же ником. Закройте Freesm и нажмите «Проверить аккаунт».
4. Нажмите **«Играть»**.

### У меня уже есть Freesm или Prism со сборкой

1. Закройте Freesm (Prism) и Minecraft. На всякий случай скопируйте папку своего экземпляра (`...\instances\<ваш экземпляр>`) на рабочий стол.
2. Не нажимайте «Установить сборку». Откройте вкладку **«Настройки»**.
3. В блоке «Freesm или Prism» нажмите **«Найти»**. Если не нашлось, нажмите **«Файл…»** и выберите `FreesmLauncher.exe` или `prismlauncher.exe`.
4. В блоке «Папка instances» проверьте путь. Если пусто: в Freesm (Prism) правый клик по вашему экземпляру → «Папка» и в лаунчере «Папка…» → выберите эту папку.
5. В списке «Экземпляр» выберите свой экземпляр. Пункт «Создать новый экземпляр сборки» создаёт отдельный, готовый вы тогда не используете.
6. На вкладке «Игрок» укажите ник (для Prism с лицензией выберите режим «Microsoft»). Нажмите «Сохранить».
7. Нажмите **«Только обновить»** и посмотрите вкладку «Журнал»: что докачано, заменено и убрано. Потом **«Играть»**.

Память и Java вашего экземпляра остаются как были, пока вы сами не включите «Менять память экземпляра» или не выберете Java.

### Я играю через Modrinth App (или другой лаунчер)

Игру в таких лаунчерах запускаете вы сами, а мой лаунчер обновляет в папке профиля моды и конфиги.

1. В Modrinth App создайте профиль: версии Minecraft и NeoForge лаунчер напишет в журнале и под названием сборки (Minecraft 1.21.1, NeoForge). Задайте Java 21 и память в настройках профиля.
2. В лаунчере: «Настройки» → «Как вы запускаете игру» → **«Modrinth App или другая папка»**.
3. Выберите профиль в списке «Профили Modrinth App». Если списка нет, нажмите «Папка…» и выберите папку профиля: в Modrinth App откройте профиль и нажмите значок папки (внутри должна лежать папка `mods`). Нажмите «Сохранить».
4. Нажмите **«Установить в папку»**, затем запускайте игру в Modrinth App. Кнопки «Играть» в этом режиме нет.
5. Когда выйдет обновление, нажмите «Обновить сборку» или «Проверить файлы».

Корень диска, личную и системные папки лаунчер выбрать не даст.

## Как пользоваться

- **«Играть»** запускает игру через Freesm (Prism) и сразу заходит на сервер. Если вышло обновление, кнопка называется «Обновить и играть»: сначала обновит файлы.
- **«Только обновить»** обновляет файлы без запуска.
- Вкладка **«Что нового»** показывает список изменений сборки.
- Вкладка **«Журнал»** показывает, что лаунчер делал. Внизу слева видно, если вышла новая версия самого лаунчера: нажмите на неё и скачайте свежий `ImperialLauncher.exe`.

## Настройки

| Настройка | Что делает |
|---|---|
| Как вы запускаете игру | «Freesm или Prism» или «Modrinth App или другая папка» |
| Java | По умолчанию выбирает Freesm. «Подобрать» находит Java 21 на компьютере, «Файл…» выбирает вручную |
| Память для игры | Применяется только если включено «Менять память экземпляра» |
| Заходить на сервер сразу | Игра открывается с подключением к серверу |
| Обновлять сборку и при запуске из Freesm | Сборка будет обновляться и когда вы запускаете игру прямо из Freesm. Если перенесёте лаунчер в другую папку, выключите и включите заново |
| Убирать посторонние моды в карантин | Моды, которых нет в сборке, переезжают в `.minecraft\.imperial\quarantine\<дата>`, не удаляясь. Помогает от конфликтов старых версий |
| Папка установки | Куда ставить Freesm при новой установке |

## Что лаунчер делает с файлами

- **Моды** (`mods`): приводит в точное соответствие со сборкой. Убранные из сборки моды удаляются (только те, что поставил сам лаунчер). Ваши посторонние моды остаются, в журнале будет предупреждение.
- **Настройки модов** (`config`): ставит один раз, если файла нет. Ваши правки не перезаписываются.
- **Файлы, которые автор сборки обновляет для всех** (например, настройки скинов): заменяются только когда у них выходит новая версия.
- **Никогда не трогает:** `options.txt` (раскладка клавиш), `servers.dat`, `saves`, `screenshots`, `logs`, `crash-reports`, `journeymap`, `xaero`, `schematics`, `backups`.
- Каждый файл скачивается во временный файл и проверяется по SHA-256, поэтому битая загрузка не попадёт в игру. Из загруженных файлов лаунчер ничего не запускает.

## Где что лежит

- Настройки лаунчера и журнал: `%APPDATA%\ImperialLauncher\` (`settings.json`, `launcher.log`).
- Служебные данные сборки: `.minecraft\.imperial\` в папке вашего экземпляра (там же карантин).
- Перед правкой настроек экземпляра рядом создаются копии `instance.cfg.imperial-bak` и `mmc-pack.json.imperial-bak`.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| «Файл занят» или «Freesm сейчас запущен» | Закройте игру и Freesm, повторите |
| «Нет связи со сборкой» | Проверьте интернет. Если интернет есть, значит, пока нет выпущенной сборки или сайт GitHub недоступен: попробуйте позже |
| Игра не запускается | Проверьте вкладку «Игрок»: ник должен совпадать с оффлайн-аккаунтом в Freesm. «Проверить аккаунт» подскажет |
| Не нашёл Freesm или папку instances | В Freesm правый клик по экземпляру → «Папка», затем в лаунчере «Папка…» |
| Конфликт модов или лишние моды | Включите «Убирать посторонние моды в карантин» и нажмите «Только обновить». Нужное верните из `.minecraft\.imperial\quarantine` |
| Нужна помощь | Пришлите файл `%APPDATA%\ImperialLauncher\launcher.log` |

Чтобы вернуть всё как было: верните копию экземпляра, сделанную перед первым запуском. Чтобы лаунчер забыл, какие файлы он ставил (и ничего сам не удалял), удалите `.minecraft\.imperial\state.json`.

## О проекте

Лаунчер написан на Python с интерфейсом на CustomTkinter, собирается в один `.exe` автоматически на GitHub Actions. Он не заменяет Freesm, а настраивает его и поддерживает сборку актуальной. Сборка раздаётся через релизы отдельного репозитория, лаунчер сам берёт оттуда список файлов.
