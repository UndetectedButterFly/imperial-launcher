# Империя — лаунчер сборки

Небольшая программа для Windows. Ставит Freesm Launcher, создаёт в нём экземпляр сборки, докачивает и обновляет
моды и конфиги из GitHub, помогает выбрать Java и память и запускает игру. Файлы игроков (раскладка клавиш,
настройки модов, миры, скриншоты) она не трогает.

## Как всё устроено

Два репозитория на GitHub:

| Репозиторий | Что в нём | Что в релизах |
|---|---|---|
| `imperial-launcher` (этот) | код лаунчера | `ImperialLauncher.exe` (собирается автоматически) |
| `imperial-pack` (папка `imperial-pack/` рядом) | конфиги сборки, `pack.json`, инструмент выпуска | `manifest.json` + файлы модов и конфигов |

Игрок скачивает `ImperialLauncher.exe` из релизов. Лаунчер берёт `manifest.json` из **последнего релиза**
репозитория сборки (`github.com/<вы>/imperial-pack/releases/latest/download/manifest.json`), сверяет хэши файлов
и скачивает только то, что изменилось.

## Быстрый старт (для вас)

1. Создайте на GitHub два репозитория: `imperial-launcher` и `imperial-pack` (публичные).
2. Залейте в первый содержимое папки `imperial-launcher/`, во второй содержимое `imperial-pack/`.
3. Репозиторий сборки по умолчанию ищется как `<владелец>/imperial-pack`. Если назвали иначе, создайте в
   `imperial-launcher` переменную: Settings → Secrets and variables → Actions → Variables → `PACK_REPO` = `владелец/имя`.
4. Выпустите лаунчер: `git tag v1.0.0 && git push --tags`. Через пару минут во вкладке Releases появится
   `ImperialLauncher.exe` (его собирает GitHub Actions на Windows, ничего ставить локально не нужно).
5. Подготовьте сборку (см. `imperial-pack/README.md`) и выложите её командой `python tools/build_manifest.py --version 1.0.0 --publish`.
6. Дайте друзьям ссылку на релиз лаунчера.

Проверить код без публикации: `python -m unittest discover -s tests` (тесты движка работают на любой ОС). Запуск окна
из исходников: `pip install -r requirements.txt` и `python main.py`. Локальная сборка exe: `build.bat`.

## Что делает лаунчер у игрока

1. «Установить сборку»: скачивает Freesm (portable) в папку установки, создаёт экземпляр (Minecraft и NeoForge
   нужных версий), выкладывает файлы сборки.
2. Вкладка «Игрок»: ник для оффлайн-режима или вход через Microsoft. Аккаунт один раз создаётся в самом Freesm,
   лаунчер проверяет, что он там есть, и запускает игру именно с ним.
3. Вкладка «Настройки»: выбор Java (поиск по компьютеру), память (меняется только если включить «Менять память экземпляра»),
   заход на сервер сразу, карантин для посторонних модов.
4. «Обновить и играть»: проверка и обновление файлов, затем запуск.
5. Игроки, у которых Freesm и экземпляр уже есть: в «Настройках» выберите папку с `FreesmLauncher.exe` и свой экземпляр
   из списка, и лаунчер возьмёт его под управление; совпадающие файлы докачиваться не будут, память и Java экземпляра
   не меняются. Поддерживается и portable-копия, и обычная установка Freesm: для обычной установки укажите файл
   `FreesmLauncher.exe` и папку `instances` (подойдёт и папка вашего экземпляра); игра в этом случае запускается без `-d`.

6. Prism Launcher поддерживается как Freesm (выберите `prismlauncher.exe`). Для Modrinth App и любых других лаунчеров есть режим
   «Modrinth App или другая папка»: лаунчер только проверяет и обновляет файлы в папке профиля, кнопки «Играть» там нет
   (профили Modrinth App хранятся в его базе данных, и запускать их снаружи я не нашёл способа).

Подробные пошаговые инструкции: `ИНСТРУКЦИЯ.md` в корне набора.

## Режимы файлов

Режим файла задаётся правилами в `pack.json` репозитория сборки.

| Режим | Что делает лаунчер | Для чего |
|---|---|---|
| `enforce` | файл на диске обязан совпадать с манифестом, битый чинится, убранный из сборки удаляется | моды |
| `update` | перезаписывает только когда в сборке вышла **новая версия** этого файла; правки пользователя живут до этого момента | `CustomSkinLoader.json`, `kubejs/` |
| `once` | кладёт, только если файла никогда не было; дальше файл принадлежит игроку (удалил — не вернётся) | большинство конфигов |
| `ignore` | не трогает | то, что не надо раздавать |

Всегда защищены, даже если попали в манифест: `options.txt`, `servers.dat`, `saves/`, `screenshots/`, `logs/`,
`journeymap/`, `xaero/`, `schematics/` и др. (список в `launcher/manifest.py`, свои пути добавляются в `protected`).

## Автообновление при запуске из самого Freesm

Переключатель «Обновлять сборку и при запуске прямо из Freesm» прописывает в экземпляр команду перед запуском
(`PreLaunchCommand`), которая вызывает `ImperialLauncher.exe --sync <папка экземпляра>`. Если лаунчер перенести в
другую папку, переключатель надо выключить и включить заново. Эта функция работает только у собранного exe.

## Безопасность

* Скачивание только по `http(s)`, каждый файл проверяется по SHA-256 и размеру, запись идёт во временный файл.
* Пути из манифеста проверяются: абсолютные пути, `..` и выход за папку игры отвергаются.
* Лаунчер ничего не запускает из загруженных файлов.
* Публикуйте релизы только со своего аккаунта: тот, кто может писать в репозиторий сборки, управляет файлами у всех игроков.
* exe, собранный PyInstaller, антивирусы иногда ругают «на всякий случай». Сверяйте `.sha256` из релиза; при
  необходимости соберите вариант `--onedir` (в `build.bat` замените `--onefile`).

## Честно о том, что проверено

Проверено тестами (41 в лаунчере и 10 в репозитории сборки, `python -m unittest discover -s tests`): движок синхронизации (все режимы, удаление,
карантин, защита путей, битые загрузки), установка Freesm из архива, создание и обновление экземпляра, правка
`instance.cfg`, генератор манифеста и совместимость манифеста с лаунчером.

Не проверено на настоящих системах (в среде разработки нет Windows и графики): внешний вид окна и поведение
CustomTkinter, запуск настоящего Freesm. Запись `instance.cfg`/`mmc-pack.json` и флаги командной строки опираются
на документацию Prism Launcher, от которого Freesm построен. Если в экземпляре что-то не подхватилось, рядом лежат
копии `*.imperial-bak`, а лаунчер всегда можно обойти: создайте экземпляр в Freesm руками.

Автоматическое создание аккаунтов в `accounts.json` сознательно не делается: формат файла чужой и меняется между
версиями, ошибка могла бы сломать список аккаунтов. Лаунчер только читает его.
